# Presentación interactiva

Abrir `../05_Presentacion_Final/RECOEVO_Carrusel_Investigacion.html` en un navegador. Navegación horizontal con botones inferiores y flechas del teclado; proporción visual 16:9 adaptable a ventana, tipografía grande y barras animadas. Incluye portada, ficha técnica, metodología, 11 láminas analíticas y cierre de gracias.

Las cifras se generan desde las transcripciones disponibles y llevan advertencias de corpus exploratorio. Las citas están anonimizadas pero pendientes de escucha/verificación contra audio.
